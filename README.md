
# 📚 Snap & Study

### Learn smarter, not harder.

Snap & Study is an AI-powered study assistant that transforms study materials into easy-to-understand learning resources.

## ✨ Features

- 📄 PDF analysis across the uploaded document
- 📝 AI-generated smart summaries
- 🔑 Important key points
- ❓ Important questions for revision
- 🎯 Interactive MCQ quizzes
- 🔄 Quiz reattempts with different questions
- 📥 Downloadable study notes in PDF format
- 🖼️ Support for image-based study materials

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- PyMuPDF
- ReportLab

## ⚙️ Installation

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Create `.streamlit/secrets.toml` and add:

   GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"

4. Start the application:

   streamlit run app.py

## 🔐 Security

Never commit API keys or secret configuration files.
